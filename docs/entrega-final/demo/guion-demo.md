# Guion de la presentación final (8 minutos)

| Tiempo | Diapositiva | Qué explicar o mostrar |
|---|---|---|
| 0:00-0:30 | 1. TutorLink | Presentar al equipo y resumir el producto: buscar un tutor, conocer su perfil y reservar una tutoría. |
| 0:30-1:15 | 2. Problema | Describir al estudiante que necesita apoyo y la falta de información para elegir tutor. Citar entrevistas y el task test documentado sin inventar métricas. |
| 1:15-2:00 | 3. Solución | Explicar la búsqueda por materia y los datos del perfil: tarifa, materias, calificación y disponibilidad publicada. |
| 2:00-5:00 | 4. Demo en vivo | Abrir el build distribuido, buscar, elegir tutor, completar el formulario, reservar y localizar la sesión en el calendario. Mostrar una validación del formulario. Si falla el equipo o la conexión, reproducir el video continuo de respaldo. |
| 5:00-5:45 | 5. Continuidad | Explicar la caché de Firestore, el historial en Room y el estado pendiente de las reservas sin red. Aclarar qué está mostrando la demo y qué tiene evidencia adicional en el repositorio. |
| 5:45-6:40 | 6. Arquitectura | Recorrer Compose, ViewModels y repositorios. Nombrar las clases reales y explicar dónde están Firestore, Room y DataStore. |
| 6:40-7:25 | 7. Calidad | Mostrar el build 1.2 (3), las 28 pruebas unitarias y el evento no fatal por credenciales inválidas. Explicar por qué es esperado. No afirmar dos descargas externas mientras falte esa evidencia. |
| 7:25-8:00 | 8. Cierre | Repetir el valor para el estudiante y dar paso a las preguntas. |

Antes de presentar: descargar el PDF y el video, abrir el build final, comprobar la cuenta y el catálogo y preparar una fecha futura válida para la reserva. Los integrantes se presentan oralmente; sus nombres no se inventaron en las diapositivas.
